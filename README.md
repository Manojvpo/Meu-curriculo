Este projeto é um site de portfólio pessoal desenvolvido com HTML, CSS e JavaScript, criado para apresentar informações profissionais, habilidades e projetos desenvolvidos.

Além de funcionar como um currículo online, o sistema permite adicionar projetos dinamicamente com links clicáveis para acesso rápido.

🚀 Funcionalidades
📄 Apresentação pessoal
💼 Currículo online
🛠️ Área de habilidades
📁 Listagem de projetos
➕ Adicionar novos projetos dinamicamente
🔗 Links clicáveis para acessar os projetos
💾 Salvamento automático dos projetos com localStorage
📱 Layout simples e responsivo
🖥️ Tecnologias Utilizadas
HTML5
CSS3
JavaScript

⚙️ Como Executar o Projeto
Faça o download ou clone este repositório:
git clone SEU_LINK_DO_GITHUB
Abra a pasta do projeto
Execute o arquivo:
index.html

Você pode abrir diretamente no navegador.

📌 Como Adicionar Projetos

Na seção “Meus Projetos”, preencha:

Nome do projeto
Descrição
Link do projeto

Depois clique em:

Adicionar

O projeto será exibido automaticamente na tela.

💾 Salvamento Automático

Os projetos adicionados são armazenados no navegador utilizando:

localStorage

Assim, os dados permanecem salvos mesmo após atualizar a página.
